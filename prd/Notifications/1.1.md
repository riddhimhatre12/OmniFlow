Extend convex/schema.ts to add real-time notifications and activity tracking.

Current: Users, Workspaces, Roles, Members, Projects, Sprints, Tasks tables exist.

Add these tables:

1. **notifications table**:
   - notificationId: auto
   - userId: ref to users (who receives the notification)
   - workspaceId: ref to workspaces
   - type: "task_assigned" | "sprint_started" | "sprint_closed" | "invite_received" | 
           "role_changed" | "member_joined" | "project_created" | "task_commented" | 
           "task_status_changed" | "mention" (enum)
   - title: string (e.g., "You were assigned a task")
   - message: string (e.g., "Sarah assigned you 'Design Homepage'")
   - read: boolean (default false)
   - readAt: optional number (timestamp when marked read)
   - actionBy: ref to users (who triggered the notification)
   - relatedResourceId: string (taskId, projectId, sprintId, etc.)
   - relatedResourceType: string (task, project, sprint, member, etc.)
   - link: string (URL to navigate to, e.g., "/projects/123/tasks/456")
   - metadata: optional object (JSON payload for extra data, e.g., { oldRole, newRole })
   - createdAt: number
   - expiresAt: optional number (auto-delete old notifications)
   - Indexes: by_userId, by_workspaceId, by_userId_and_read, by_createdAt

2. **activity_feed table** (optional but recommended for audit & analytics):
   - activityId: auto
   - workspaceId: ref to workspaces
   - userId: ref to users (who performed action)
   - action: string (e.g., "task_created", "sprint_started", "member_invited", "role_updated")
   - resourceType: string (task, project, sprint, member, workspace)
   - resourceId: string
   - resourceName: string (e.g., "Design Homepage")
   - changes: optional object (before/after values for updates)
   - description: string (human-readable: "[User] created task 'Design Homepage'")
   - createdAt: number
   - Indexes: by_workspaceId, by_userId, by_createdAt, by_resourceType

3. **notification_preferences table** (per user, per workspace):
   - preferenceId: auto
   - userId: ref to users
   - workspaceId: ref to workspaces
   - taskAssignedEnabled: boolean (default true)
   - taskCommentedEnabled: boolean (default true)
   - sprintStartedEnabled: boolean (default true)
   - sprintClosedEnabled: boolean (default true)
   - memberInvitedEnabled: boolean (default true)
   - memberJoinedEnabled: boolean (default true)
   - roleChangedEnabled: boolean (default true)
   - mentionEnabled: boolean (default true)
   - emailNotifications: boolean (default false)
   - Indexes: by_userId_workspace (compound unique index)

Include:
- Full TypeScript type definitions
- Proper enum values for notification types
- Timestamp fields for ordering and expiry
- Relationship to resource (task, project, etc.) for deep linking
- Metadata field for flexible extra data
- Preference tracking per user per workspace
