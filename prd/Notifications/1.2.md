Create convex/notifications.ts with notification creation, retrieval, and management.

Tech: Convex, TypeScript, real-time subscriptions

Build these functions:

**QUERIES (read-only, real-time):**

1. getUserNotifications(userId, workspaceId, limit = 20)
   - Return unread notifications first (sorted by createdAt desc)
   - Include: notificationId, type, title, message, read, createdAt, actionBy (user info)
   - Limit to last N notifications
   - Real-time: updates as new notifications arrive
   - Return: [{ notificationId, type, title, message, read, link, actionBy, createdAt }]

2. getUnreadNotificationCount(userId, workspaceId)
   - Return count of unread notifications
   - Used for badge counter
   - Real-time: updates instantly on mark-as-read

3. getNotificationDetails(notificationId)
   - Full notification object with:
     * All fields
     * Expanded user info (actionBy)
     * Resource details (project name, task title, etc.)

4. getUserNotificationPreferences(userId, workspaceId)
   - Get user's notification settings
   - Return: { taskAssignedEnabled, taskCommentedEnabled, ... }

5. getActivityFeed(workspaceId, limit = 50, resourceType?)
   - Return activity log for workspace
   - Optional filter by resourceType (task, project, sprint)
   - Sort by createdAt descending
   - Include: userId (user info), action, resourceName, description, createdAt
   - Used for activity feed sidebar/widget

**MUTATIONS (write):**

1. createNotification(userId, workspaceId, type, title, message, actionBy, 
                      relatedResourceId, relatedResourceType, link, metadata?)
   - Validate: notification type is valid enum
   - Check user's notification preferences (if type is disabled, don't create)
   - Create notification record
   - Return: notification object
   - Called internally by other functions (task create, sprint start, etc.)

2. markNotificationAsRead(notificationId)
   - Set read = true, readAt = now
   - Return: updated notification

3. markAllNotificationsAsRead(userId, workspaceId)
   - Set read = true for all unread notifications in workspace
   - Return: count of updated notifications

4. deleteNotification(notificationId)
   - Delete single notification
   - Return: success

5. clearAllNotifications(userId, workspaceId)
   - Delete all notifications for user in workspace
   - Confirmation: "Clear all X notifications?"
   - Return: success

6. updateNotificationPreferences(userId, workspaceId, preferences)
   - preferences: { taskAssignedEnabled, emailNotifications, ... }
   - Update or create notification_preferences record
   - Return: updated preferences

7. logActivity(workspaceId, userId, action, resourceType, resourceId, 
               resourceName, description, changes?)
   - Create activity_feed record
   - Called internally whenever major action happens (task created, sprint started, etc.)
   - Returns: activity object
   - Note: This is an internal function, called from other mutations

Include:
- Notification preference validation
- Auto-expiry cleanup (optional: expire notifications > 30 days old)
- Prevent duplicate notifications (e.g., don't notify twice for same task assignment)
- Permission validation: only notify if user has workspace access
- Real-time Convex subscriptions so frontend gets instant updates
- Structured logging for audit trail
- Error handling & clear messages
