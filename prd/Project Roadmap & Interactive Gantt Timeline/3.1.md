Create src/pages/ProjectRoadmapPage.tsx with interactive Gantt chart view.

Route: /projects/:projectId/roadmap

Tech: React 19, Gantt library (react-gantt-chart or similar, or custom SVG)

Layout:

1. **Page Header**:
   - Breadcrumb: Projects > [Project Name] > Roadmap
   - View toggle buttons: Gantt (default) | Timeline | Milestone | Table
   - Date range selector: Start date, End date (filter visible items)
   - "Export Roadmap" button (PDF/PNG)
   - Zoom controls: Zoom in/out (daily → weekly → monthly view)

2. **Gantt Chart View** (main):
   - Left panel (Tasks/Items):
     * List of sprints and tasks/milestones
     * Hierarchical: Sprint > Tasks within sprint
     * Drag-to-reorder sprints (optional)
   - Right panel (Timeline):
     * Calendar grid showing dates
     * Horizontal bars for each sprint/task showing:
       - Start date to end date
       - Color-coded by status (planning=gray, active=blue, completed=green)
       - Milestone markers (diamond shape)
       - Dependencies (arrow lines connecting tasks)
     * Bars are draggable to adjust dates
     * Hover: shows sprint name, duration, status
     * Click: opens sprint details modal

3. **Gantt Features**:
   - **Today indicator**: Vertical line showing current date
   - **Critical path**: Highlight path of tasks that affect project end date (optional)
   - **Dependencies**: If implemented, show arrows linking dependent tasks
   - **Milestones**: Diamond shapes for project milestones
   - **Drag-to-adjust**: Drag sprint/task bar edges to resize dates
   - **Scroll**: Horizontal scroll to see full date range
   - **Hover tooltips**: Show sprint goal, team members, progress %

4. **Item Details (on Gantt bar click)**:
   - Modal showing:
     * Sprint/Task name
     * Current status and progress
     * Start/end dates
     * Team members assigned
     * Tasks count & completion
     * "Edit" button to change dates
   - Confirm date changes

5. **Milestone View** (alternative tab):
   - Show only key milestones (project deadlines)
   - Vertical timeline
   - Each milestone card shows:
     * Milestone name (e.g., "v2.0 Release")
     * Target date
     * Status (on track / at risk / delayed)
     * Connected sprints/tasks count
     * Description

6. **Table View** (alternative tab):
   - Table of all sprints/tasks with:
     * Name | Start Date | End Date | Duration | Status | Progress | Team
   - Sortable by any column
   - Filterable by status

Include:
- Date picker library (react-datepicker or similar)
- Gantt chart library (react-gantt-chart, react-timeline-gantt, or custom SVG)
- Drag-to-resize functionality
- Real-time data from Convex queries
- Responsive design (on mobile, show table view by default)
- Export to PDF (optional: use react-pdf or jsPDF)
- Design tokens from index.css
- Accessibility: keyboard navigation, ARIA labels

NOTE: Gantt implementation can be:
- Option A: Use existing library (react-gantt-chart)
- Option B: Use Recharts for custom timeline (simpler)
- Option C: Custom SVG with React (most control, more code)
