Extend convex/schema.ts and create convex/milestones.ts for project milestones.

Add to schema.ts:

1. **project_milestones table**:
   - milestoneId: auto
   - projectId: ref to projects
   - workspaceId: ref to workspaces
   - name: string (e.g., "v1.0 Release", "Beta Launch")
   - description: optional string
   - targetDate: number (timestamp)
   - status: "planned" | "on_track" | "at_risk" | "completed" (enum)
   - completedDate: optional number (when actually completed)
   - linkedSprints: array of sprintIds (sprints that feed into this milestone)
   - createdAt: number
   - createdBy: ref to users
   - Indexes: by_projectId, by_workspaceId, by_targetDate, by_status

---

Create convex/milestones.ts:

QUERIES:

1. getProjectMilestones(projectId)
   - Return all milestones for project
   - Sort by targetDate ascending
   - Include: milestoneId, name, targetDate, status, linkedSprints count, progress

2. getMilestoneDetails(milestoneId)
   - Full milestone object with linked sprint details

3. getMilestoneProgress(milestoneId)
   - Calculate progress % based on linked sprints:
     * Get all linked sprints
     * Sum completed story points / total story points
     * Return: { totalPoints, completedPoints, progressPercent, linkedSprints }

MUTATIONS:

1. createMilestone(projectId, workspaceId, userId, name, description, targetDate)
   - Create milestone record
   - Log activity: "created milestone [name]"
   - Return: milestone object

2. updateMilestone(milestoneId, name?, description?, targetDate?, linkedSprints?)
   - Update milestone fields
   - If status changed: log activity
   - Return: updated milestone

3. linkSprintToMilestone(milestoneId, sprintId)
   - Add sprintId to milestone.linkedSprints array
   - Auto-update milestone status based on sprint status
   - Return: updated milestone

4. unlinkSprintFromMilestone(milestoneId, sprintId)
   - Remove sprintId from milestone.linkedSprints
   - Return: updated milestone

5. completeMilestone(milestoneId)
   - Set status = "completed"
   - Set completedDate = now
   - Log activity
   - Return: updated milestone

6. deleteMilestone(milestoneId)
   - Delete milestone (only if no linked sprints)
   - Return: success or error

Include:
- Permission checks
- Date validation
- Activity logging
- Real-time milestone status updates based on linked sprint progress
