Create/Update src/components/ui/AvatarUploader.tsx for user profile pictures.

Used in: ProfilePage, UserCard, TopBar user dropdown

Features:

1. **Avatar Display**:
   - Show current avatar (from user profile)
   - If no avatar: show user initials (e.g., "SE" for Shubham Eknath)
   - Circular, 64x64px by default

2. **Upload Trigger**:
   - Hover over avatar → show "Change Avatar" button (pencil icon)
   - Click → opens file picker or shows upload modal

3. **Avatar Upload Modal**:
   - <CloudinaryUploader uploadPreset="omniflow_avatars" />
   - Image preview after upload
   - Drag-to-crop tool (optional: use react-image-crop)
   - "Use This Avatar" button
   - On confirm:
     * Call Convex saveAvatarMetadata
     * Update user profile avatar URL
     * Close modal & refresh avatar display
     * Show toast: "Avatar updated"

4. **Display Options**:
   - As profile picture in TopBar user menu
   - In sidebar user card at bottom
   - In team member list (TeamMembersPage)
   - In task comments (commenter avatar)
   - In notification center (action by user)

Include:
- useCurrentUser() hook for session updates
- Real-time avatar sync across all components
- Fallback to initials if no avatar
- Image optimization via Cloudinary
- Error handling & retry
- Mobile responsive
- Accessibility: alt text, ARIA labels
