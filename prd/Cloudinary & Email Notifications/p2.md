Create src/components/CloudinaryUploader.tsx - reusable file upload component 
for task attachments, user avatars, and workspace logos.

Tech: React 19, Cloudinary SDK, react-dropzone

Build these components:

1. **<CloudinaryUploader />** (main component)
   Props:
   - uploadPreset: string (e.g., "omniflow_attachments")
   - onUploadSuccess: (response) => void
   - onUploadError: (error) => void
   - maxFileSize?: number (bytes, default 50MB)
   - allowedFormats?: string[] (default: all)
   - description?: string

   Features:
   - Drag-and-drop zone with visual feedback
   - Click to browse files
   - File validation (size, format)
   - Upload progress bar (%)
   - Thumbnail preview for images
   - Loading state during upload
   - Error message display
   - Cancel upload button

2. **Upload Flow**:
   - User selects/drags file
   - Validate size & format client-side
   - Call Convex generateUploadSignature mutation
   - Upload directly to Cloudinary using unsigned preset
   - On success: call Convex saveAttachmentMetadata (or saveAvatarMetadata)
   - Show success toast
   - Trigger onUploadSuccess callback
   - On error: show error message

3. **Styling**:
   - Use design tokens from index.css
   - Drag-over state: highlight border + background color change
   - Progress bar animation
   - Image thumbnail: max 120x120px, rounded corners

---

Example Usage:

```typescript
<CloudinaryUploader
  uploadPreset="omniflow_attachments"
  onUploadSuccess={(response) => {
    console.log('File uploaded:', response);
    // Refresh attachments list
  }}
  onUploadError={(error) => {
    showToast('Upload failed: ' + error.message, 'error');
  }}
  maxFileSize={50 * 1024 * 1024} // 50MB
/>
```

Include:
- react-dropzone for drag-drop
- cloudinary-js SDK for direct uploads
- File type icons (using lucide-react)
- Accessible file input
- Keyboard support (Tab, Enter)
- ARIA labels for screen readers
- Mobile responsive (full width on small screens)
