Add workspace logo upload to WorkspaceSettingsPage (or create one).

Route: /workspace/:workspaceId/settings (or /settings/workspace)

Features:

1. **Workspace Logo Section**:
   - Current logo display (or placeholder)
   - "Upload Logo" button
   - Trigger Cloudinary uploader modal

2. **Logo Upload Modal**:
   - <CloudinaryUploader uploadPreset="omniflow_workspace_logos" />
   - Show logo preview (200x200px)
   - "Save Logo" button
   - On success:
     * Call Convex saveWorkspaceLogoMetadata
     * Update workspace avatar in sidebar & header
     * Show toast: "Workspace logo updated"

3. **Where Logo Appears**:
   - Sidebar workspace selector (next to workspace name)
   - DashboardPage header (workspace info card)
   - Workspace switcher dropdown

Include:
- useWorkspaceAuth() for Admin/Owner permission check
- Real-time update across all workspace displays
- Logo compression via Cloudinary
- Error handling
- Mobile responsive
- Accessibility
