Extend convex/schema.ts to add comments and file attachments to tasks.

Add these tables:

1. **task_comments table**:
   - commentId: auto
   - taskId: ref to tasks
   - workspaceId: ref to workspaces
   - userId: ref to users (who wrote comment)
   - content: string (markdown or plain text)
   - mentions: array of { userId, userName } (for @mentions)
   - reactions: optional object (emoji reactions, e.g., { "👍": [userId1, userId2] })
   - createdAt: number
   - updatedAt: number
   - editedBy: optional ref to users (if edited by someone else, e.g., moderator)
   - isDeleted: boolean (soft delete for audit)
   - deletedAt: optional number
   - deletedBy: optional ref to users
   - Indexes: by_taskId, by_userId, by_workspaceId, by_taskId_and_createdAt

2. **task_attachments table**:
   - attachmentId: auto
   - taskId: ref to tasks
   - workspaceId: ref to workspaces
   - uploadedBy: ref to users
   - fileName: string
   - fileType: string (e.g., "image/png", "application/pdf", "video/mp4")
   - fileSize: number (bytes)
   - storageKey: string (Convex file storage key, e.g., "file-xyz-123")
   - url: string (downloadable URL via Convex file API)
   - description: optional string (user-provided file label)
   - uploadedAt: number
   - isDeleted: boolean (soft delete)
   - deletedAt: optional number
   - Indexes: by_taskId, by_uploadedBy, by_workspaceId, by_taskId_and_uploadedAt

3. **task_subscribers table** (optional, for watch notifications):
   - subscriberId: auto
   - taskId: ref to tasks
   - userId: ref to users
   - subscribedAt: number
   - Indexes: by_taskId, by_userId, UNIQUE(taskId, userId)

Include:
- Full TypeScript types
- Soft deletes for audit trail (don't permanently remove comments)
- Emoji reaction support for social engagement
- @mention tracking for notifications
- Convex file storage integration (fileStorageKey)
- Proper indexing for query performance
