Create convex/comments.ts and convex/attachments.ts for task collaboration.

Tech: Convex, TypeScript, real-time subscriptions, Convex File API

Build these functions:

**convex/comments.ts:**

QUERIES (real-time):

1. getTaskComments(taskId, limit = 50)
   - Return all comments on task (sorted by createdAt asc, oldest first)
   - Include: commentId, content, userId (user info), mentions, reactions, createdAt, updatedAt
   - Skip soft-deleted comments (isDeleted = false)
   - Real-time: updates as comments are added/edited
   - Return: [{ commentId, userId (with name/avatar), content, reactions, createdAt }]

2. getCommentDetails(commentId)
   - Full comment object with user info and edit history

MUTATIONS (write):

1. createComment(taskId, workspaceId, userId, content, mentions?)
   - Validate: user has task:comment permission
   - Validate: content is not empty (min 1 char, max 5000 chars)
   - Parse @mentions in content (e.g., "@Sarah") and validate users exist
   - Create comment record
   - Extract mentioned users and create notifications:
     * For each mentioned user: createNotification(..., "mention", 
       "[User] mentioned you in task [Title]", ...)
   - Extract any URLs or linked task IDs (optional: auto-link)
   - Log activity: logActivity(workspaceId, userId, "task_commented", "task", taskId, ...)
   - Return: comment object

2. editComment(commentId, newContent, editedBy)
   - Validate: only comment author or workspace admin can edit
   - Update content, updatedAt, editedBy
   - Return: updated comment

3. deleteComment(commentId, deletedBy)
   - Soft delete: set isDeleted = true, deletedAt = now, deletedBy
   - Deleted comment still visible to admins in audit log, but hidden from regular users
   - Return: success

4. addReaction(commentId, userId, emoji)
   - emoji: single emoji character (e.g., "👍", "❤️", "🎉")
   - Add userId to reactions[emoji] array (if not already there)
   - If already reacted: remove reaction (toggle)
   - Return: updated reactions

5. removeReaction(commentId, userId, emoji)
   - Remove userId from reactions[emoji] array
   - Return: updated reactions

---

**convex/attachments.ts:**

QUERIES (real-time):

1. getTaskAttachments(taskId)
   - Return all attachments on task (sorted by uploadedAt desc, newest first)
   - Include: attachmentId, fileName, fileType, fileSize, url, description, uploadedBy (user info), uploadedAt
   - Skip soft-deleted attachments
   - Return: [{ attachmentId, fileName, fileSize, url, uploadedBy, uploadedAt, description }]

MUTATIONS (write):

1. uploadAttachment(taskId, workspaceId, userId, file, description?)
   - NOTE: In Convex, file upload requires using Convex's file storage API
   - Use: const storageId = await ctx.storage.store(fileData)
   - Create attachment record with storageId
   - Generate download URL (Convex provides built-in URL)
   - Validate: fileSize < 50MB (or your limit)
   - Validate: file type is allowed (no .exe, .dll, etc.)
   - Create attachment_attachments record
   - Log activity: logActivity(workspaceId, userId, "file_uploaded", "task", taskId, ...)
   - Return: attachment object with download URL

2. deleteAttachment(attachmentId, deletedBy)
   - Soft delete: set isDeleted = true, deletedAt = now
   - Note: Convex storage file remains (cleanup optional via scheduled job)
   - Return: success

3. getAttachmentDownloadUrl(attachmentId)
   - Return URL to download file from Convex storage
   - Can be used for direct links in UI
